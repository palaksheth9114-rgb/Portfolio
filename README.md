## 💻 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/palaksheth9114-rgb/Portfolio.git
   cd Portfolio
   ```

2. **Serve the project:**
   You can open `index.html` directly in any web browser, or launch a local HTTP server:
   ```bash
   npx http-server -p 8080 -o "index.html"
   ```
